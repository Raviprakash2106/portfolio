## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Raviprakash2106/portfolio.git
```

### 2. Open the project

```bash
cd portfolio
```

### 3. Run the website

Since this is a static HTML/CSS/JavaScript project, you can simply open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code for local development.
